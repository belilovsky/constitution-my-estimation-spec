Версия 1.3 · 2026-09-06. Детализация W-009/W-010/W-011/W-012/W-017/W-021/W-023, не дополнительный оплачиваемый блок.

Основание: выбранные публичные ответы и исходные потребители снимка `292f5a639bcbc3ae7a89b95d2bde6862cb492837`. Ниже фиксируется минимальное обязательное ядро новой поставки. Наличие исходника не доказывает, что Android был испытан в эксплуатации. Все примеры в [fixtures.json](fixtures.json) синтетические, не правовые утверждения.

## 1. Ядро читательского API

Все адреса ниже — GET, без авторизации читателя. `lang=ru|kk|en`, значение по умолчанию `ru`; неподдерживаемое значение нормализуется в `ru`. Кодировка UTF-8. Списки — массивы, в том числе пустые; пустая выдача — успешный ответ, не ошибка. Поле не может молча переименовываться. Дополнительные поля допустимы.

| Адрес | Параметры помимо lang | Ответ 200 и обязательная структура |
| --- | --- | --- |
| `/api/featured` | Нет | Массив Preview, не объект `items`; не более 12 карточек |
| `/api/all` | Нет | Объект `items: Preview[]`; все опубликованные карточки выбранного языка |
| `/api/search` | `q`: 1–200 символов; `limit`: целое 1–50, по умолчанию 20 | `{items: Preview[]}`; пробельный запрос после trim даёт пустой массив; количество не больше limit |
| `/api/item/{slug}` | Устойчивый slug, URL-encoded | Detail; неизвестный slug — 404 |
| `/api/glossary` | Нет | `{items: Term[]}`; id — число, term/short/definition — строки |
| `/api/random-term` | Нет | Одна запись: term, short, all_href — строки; при наличии записи также id, definition, anchor; отсутствие — пустые term/short |
| `/api/suggest` | `q`: 0–200; `limit`: 1–20, по умолчанию 8 | `[q, titles[], descriptions[], urls[]]`; длины трёх массивов равны; пустой запрос — три пустых массива |
| `/api/basics` | Нет | title/intro — строки, sections — массив объектов title/content; источники и подписи по общему корпусу |
| `/compare/data.json` | Нет | `{sections: [{id, title, items: Comparison[]} ]}`; 8 разделов, всего 26 сравнений на язык |
| `/full-text/data.jsonl` | Нет | По одному объекту Segment на непустую строку; 97 сегментов на язык |

Preview: `slug`, `question`, `short_answer` — строки; `section` — объект со строками `code`, `title`. Дополнительные `code`, `kind`, `read_time_minutes` допустимы. Для нового результата обязательны непустые slug/question и корректный язык; старые запасные имена canonical_slug/title/summary не заменяют фиксированные основные поля.

Detail: поля Preview и `blocks` с пятью строками `answer_html`, `facts_html`, `what_not_change_html`, `where_detailed_html`, `misconceptions_html`; пустые дополнительные блоки допустимы. Ссылки на статьи и источники доступны в `article_refs` и `source_records` (массивы; точная структура в [fixtures.json](fixtures.json), поле `responses.detail`); HTML очищен от исполняемого содержимого. Требования к этим полям — целевая поставка, не утверждение об их непустоте во всех старых записях.

Comparison: id/title/before/after/editorial_note — строки; `references` содержит массивы объектов `{article_number: 1}` в ключах `1995` и `2026`, article_number — целое число; дополнительные поля объекта допустимы. Массив чисел вместо объектов несовместим с Android-потребителем. Segment: id/type/text/canonical_url — строки, paragraphs — массив строк; для статьи article/section — целые числа, для преамбулы могут отсутствовать. ID сохраняются при смене формата.

Отсутствующий обязательный q, неверный limit или превышение длины — 422. Недоступный необходимый ресурс — 503; превышение заданной квоты — 429, если она применяется к данному API. Тела ошибок не содержат секретов; клиент различает их по HTTP-коду. Точная форма текста ошибки не является контрактом. Это целевые проверки новой поставки, не результаты стресс-теста действующего сервиса.

Один материал и одна его версия служат источником всех представлений. ## 3. Справки, диаграммы и обложки

Это детализация W-010/W-011, а не новые работы. Входы — согласованный корпус выбранного среза, язык RU/KK/EN и дата подготовки. Исполнитель может использовать готовые шаблоны, библиотеки визуализации и средства автоматической сборки. Языки, PNG/WebP и SVG/PNG — варианты одного результата, не самостоятельные разработки.

## 4. Контрольный набор помощника

Подрядчик в W-012 готовит 30 вопросов для каждого из трёх языков, ожидаемые ответы (или допустимый отказ/ограничение ответа) и ссылки на подтверждающие фрагменты уже принятого корпуса. В набор входят обычные вопросы, отсутствующие сведения, спорные формулировки и удалённые/непроверенные источники. Это приёмочные примеры, не 90 новых редакционных статей и не новое исследование права.

Редактор или юридический рецензент, назначенный заказчиком, утверждает предметный смысл вопросов, ожидаемых ответов и источников; подрядчик не утверждает собственный эталон вместо заказчика. Подрядчик выполняет технический прогон, фиксирует фактические ответы, цитаты, расхождения и повторную проверку исправлений в W-017. Неутверждённый эталон не считается успешно пройденной предметной приёмкой. Заказчик обеспечивает утверждение до итогового прогона; задержка согласования отмечается отдельно.

Подготовка W-012, технический контроль W-017 и предметное утверждение заказчиком — разные обязанности, но не дополнительные повторные начисления уже включённых проверок. Правило сохраняется и при переданном корпусе W-091; его предметная приёмка не заменяет утверждение контрольного набора.

## 5. Приёмка

Для каждого языка: непустой и пустой ответ, неизвестная карточка, некорректные параметры, удалённый/черновой материал, корректное декодирование JSON/JSONL; дополнительные поля не ломают клиента. Android-потребитель использует именно `items` и `sections[].items`: замена на `results` не принимается. После смены версии кеш не маскирует несовместимость.

[Проверка примеров](validate.mjs) проверяет структуру синтетического ядра и отклоняет известные повреждения. Это не полная контрактная/нагрузочная приёмка продукта: её исполнитель проводит в W-017/W-023. Неописанные частные зависимости раскрываются как отклонения до договора, а не добавляются задним числом.
